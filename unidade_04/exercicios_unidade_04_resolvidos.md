# U04-A07 — Exercícios de múltipla escolha da Unidade 4

> **Resolução.** A alternativa escolhida está marcada com [x] e justificada abaixo de cada questão. As respostas foram dadas antes da consulta ao gabarito da disciplina e depois conferidas com ele.

## Questão 1 — Variáveis

Código municipal numérico é:

- [ ] **A.** medida contínua
- [x] **B.** identificador
- [ ] **C.** proporção
- [ ] **D.** variância


**Resposta: B.** O código numérico distingue municípios; é identificador, não medida.

## Questão 2 — Frequências

Uma proporção exige declarar:

- [ ] **A.** a cor
- [x] **B.** o denominador
- [ ] **C.** a moda
- [ ] **D.** o OCR


**Resposta: B.** Uma proporção só é interpretável quando o denominador é declarado.

## Questão 3 — Centro

Qual medida é mais sensível a um extremo alto?

- [x] **A.** média
- [ ] **B.** mediana
- [ ] **C.** moda
- [ ] **D.** quartil


**Resposta: A.** A média usa todos os valores e reage fortemente a um extremo alto.

## Questão 4 — Dispersão

O desvio-padrão descreve:

- [ ] **A.** categoria modal
- [x] **B.** dispersão em torno da média
- [ ] **C.** causalidade
- [ ] **D.** tamanho do corpus


**Resposta: B.** O desvio-padrão resume o afastamento dos valores em torno da média, na unidade original.

## Questão 5 — Quartis

O intervalo interquartil é:

- [x] **A.** Q3 menos Q1
- [ ] **B.** máximo menos mínimo
- [ ] **C.** média menos moda
- [ ] **D.** variância ao quadrado


**Resposta: A.** IQR = Q3 − Q1, a amplitude da metade central dos valores.

## Questão 6 — Extremos

Um caso além de 1,5×IQR deve:

- [ ] **A.** ser apagado
- [x] **B.** ser inspecionado
- [ ] **C.** provar erro
- [ ] **D.** confirmar hipótese


**Resposta: B.** A regra de 1,5 IQR sinaliza candidatos à inspeção, nunca exclusão automática ou prova de erro.

## Questão 7 — Contingência

Proporções por linha mostram:

- [x] **A.** composição dentro de cada linha
- [ ] **B.** causalidade
- [ ] **C.** média textual
- [ ] **D.** OCR


**Resposta: A.** Com o total da linha como denominador, a tabela mostra a composição dentro de cada linha.

## Questão 8 — Tokenização

Tokenizar significa:

- [x] **A.** segmentar segundo regra
- [ ] **B.** traduzir
- [ ] **C.** testar hipótese
- [ ] **D.** remover contexto sem registro


**Resposta: A.** Tokenizar é segmentar o texto em unidades segundo uma regra declarada.

## Questão 9 — Normalização

Converter tudo em minúsculas pode:

- [ ] **A.** preservar toda distinção
- [x] **B.** apagar informação de capitalização
- [ ] **C.** calcular quartis
- [ ] **D.** criar PDF


**Resposta: B.** A conversão para minúsculas apaga a distinção entre, por exemplo, nomes próprios e palavras comuns.

## Questão 10 — Frequência textual

Frequência relativa divide por:

- [x] **A.** total de tokens relevante
- [ ] **B.** número de gráficos
- [ ] **C.** mediana
- [ ] **D.** IQR


**Resposta: A.** A frequência relativa divide pelo total de tokens do conjunto declarado (N ou Nc).

## Questão 11 — Concordância

Concordâncias servem para:

- [x] **A.** recuperar contexto local
- [ ] **B.** provar associação
- [ ] **C.** remover extremos
- [ ] **D.** calcular variância


**Resposta: A.** A concordância devolve o contexto local de cada ocorrência.

## Questão 12 — N-gramas

Um bigrama contém:

- [x] **A.** duas unidades adjacentes
- [ ] **B.** dois quartis
- [ ] **C.** duas tabelas
- [ ] **D.** duas hipóteses


**Resposta: A.** Bigrama é um par de unidades adjacentes dentro de um mesmo documento.

## Questão 13 — Colocações

PMI exige cautela porque:

- [x] **A.** favorece eventos raros
- [ ] **B.** é sempre causal
- [ ] **C.** não usa palavras
- [ ] **D.** mede mediana


**Resposta: A.** O PMI favorece eventos raros; por isso exige frequência mínima e retorno às concordâncias.

## Questão 14 — Diversidade

TTR bruta é afetada por:

- [x] **A.** tamanho do texto
- [ ] **B.** cor do gráfico
- [ ] **C.** ano apenas
- [ ] **D.** tipo do PDF


**Resposta: A.** A TTR bruta tende a cair quando o texto cresce; por isso se compara com tamanho fixo.

## Questão 15 — Barras

Barras são adequadas principalmente para:

- [x] **A.** categorias
- [ ] **B.** texto integral
- [ ] **C.** causalidade
- [ ] **D.** OCR


**Resposta: A.** Barras comparam valores entre categorias.

## Questão 16 — Histograma

A aparência do histograma depende:

- [x] **A.** dos intervalos
- [ ] **B.** da moda apenas
- [ ] **C.** do título apenas
- [ ] **D.** do ID


**Resposta: A.** Mudar os limites dos intervalos pode mudar a forma visível do histograma.

## Questão 17 — Dispersão

Um padrão de pontos prova causalidade?

- [ ] **A.** sim
- [x] **B.** não
- [ ] **C.** apenas com cor
- [ ] **D.** sempre em HD


**Resposta: B.** Um padrão em gráfico de dispersão descreve variação conjunta; não demonstra causalidade.

## Questão 18 — Relatório

Uma hipótese exploratória deve ser:

- [x] **A.** provisória e acompanhada de alternativas
- [ ] **B.** tratada como confirmada
- [ ] **C.** omitida
- [ ] **D.** chamada significativa

**Resposta: A.** Hipóteses exploratórias são provisórias e acompanhadas de explicações alternativas.
